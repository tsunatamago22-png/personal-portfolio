# Personal Portfolio

エンジニアへのキャリアチェンジに向けて制作した、
オリジナルポートフォリオサイトのデザインです。

これまでの経験や人物像、現在できること、制作物、
そしてこれから目指すエンジニア像まで、
一つのストーリーとして伝わるよう設計しました。

## Concept

「この人は、何者だろう？」

一般的なポートフォリオの型にとらわれず、
異業種での経験や自分らしさが伝わる構成を目指しました。
